# Planer — план дальнейшей разработки

## Текущее состояние

Planer — универсальный персональный планировщик задач, целей, привычек и продуктивности.

Пользователь самостоятельно формирует план, создаёт группы и задачи, определяет обязательность выполнения и настраивает микро-паузы.

Основные разделы:

- **Сегодня** — задачи выбранного дня, прогресс и виджеты.
- **Прогресс** — XP, уровни, серии дней, календарь и графики.
- **Настройки** — награды, микро-паузы, резервное копирование и сброс данных.

Хранение данных сейчас организовано через Zustand и LocalStorage.

## Принципы разработки

1. Пользователь сам определяет содержание своего плана.
2. Не добавлять обязательные тренировки, упражнения или фиксированный распорядок.
3. Сохранять разделение плана, настроек и прогресса.
4. Не терять историю выполнения при редактировании плана.
5. Не начислять XP повторно за одно и то же действие.
6. Новые функции добавлять небольшими проверяемыми этапами.
7. После каждого пакета проверять сборку и тесты.
8. Не удалять существующие функции без проверки их использования.
